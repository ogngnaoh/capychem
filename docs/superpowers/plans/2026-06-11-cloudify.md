# Cloudify (Slice 4 `03-cloudify`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move QED oracle scoring from a local harness subprocess to a deployed Modal worker, behind an env-selected backend that keeps the local path for CI; add a RunCost table + a dormant-but-real dollar cost gate; close the walking-skeleton milestone with a browser-driven cloud run.

**Architecture:** Scoring routes through a new `score_batch_async` (oracle.py) selected by `CAPYCHEM_ORACLE_BACKEND` — `local` wraps today's subprocess in `asyncio.to_thread`; `modal` awaits a deployed `capychem-worker.score` function whose 3.10 container shells out to the unchanged `harness/.../score.py`. Per-call cost rides on `OracleResult.cost_usd`, lands on `OracleCall.compute_cost_usd`, and the runner aggregates it into a new `RunCost` row each generation, tripping a clean `cost_capped` termination over a dollar cap.

**Tech Stack:** Python 3.12 (modern) + Modal + SQLAlchemy 2.0 async + FastAPI + LangGraph; Python 3.10 harness (PyTDC 0.3.6) only inside the Modal container; Next.js 16 + vitest on the web side.

**Predecessor docs:** spec `docs/superpowers/specs/2026-06-11-cloudify-design.md`; slice doc `docs/00-walking-skeleton/03-cloudify.md`.

**Backend note for every task:** the default `CAPYCHEM_ORACLE_BACKEND=local` keeps `uv run pytest` fully green with no Modal. Only Task 5's manual smoke needs a Modal account + `MODAL_TOKEN_ID`/`MODAL_TOKEN_SECRET` in env.

"""Run cost aggregation + the dollar cost-cap config (slice 4).

oracle_cost_usd is summed from OracleCall.compute_cost_usd; the runner upserts a
RunCost row each generation and trips a clean termination over cost_cap_usd().
LLM cost is 0 until milestone 02.
"""
from __future__ import annotations

import os

from capychem.db.models import OracleCall, RunCost
from sqlalchemy import func, select
from sqlalchemy.ext.asyncio import AsyncSession

_DEFAULT_COST_CAP_USD = 50.0  # G2: ~$50/run


def cost_cap_usd() -> float:
    return float(os.environ.get("CAPYCHEM_COST_CAP_USD", _DEFAULT_COST_CAP_USD))


async def oracle_cost_so_far(session: AsyncSession, run_id: int) -> float:
    total = await session.scalar(
        select(func.coalesce(func.sum(OracleCall.compute_cost_usd), 0.0)).where(
            OracleCall.run_id == run_id
        )
    )
    return float(total or 0.0)


async def record_oracle_cost(session: AsyncSession, run_id: int, oracle_usd: float) -> RunCost:
    """Upsert the run's RunCost row with the latest oracle cost. llm_cost_usd stays 0."""
    row = await session.scalar(select(RunCost).where(RunCost.run_id == run_id))
    if row is None:
        row = RunCost(run_id=run_id)
        session.add(row)
    row.oracle_cost_usd = oracle_usd
    row.total_usd = row.llm_cost_usd + oracle_usd
    await session.commit()
    return row
```

import asyncio  # add to the import block

_DEFAULT_ORACLE_USD_PER_SEC = 4e-5  # placeholder ~Modal CPU core-second; configure via env.
                                    # NOT a price guarantee (PRD N6 / cost-discipline framing).
_MODAL_APP = "capychem-worker"
_MODAL_FN = "score"


def _oracle_backend() -> str:
    return os.environ.get("CAPYCHEM_ORACLE_BACKEND", "local")


def oracle_usd_per_sec() -> float:
    return float(os.environ.get("CAPYCHEM_ORACLE_USD_PER_SEC", _DEFAULT_ORACLE_USD_PER_SEC))


def _modal_score_fn() -> Any:
    """Look up the deployed/serving Modal worker function. Imported lazily so the
    `local` backend (CI) never needs `modal` and never imports it at module load."""
    import modal

    return modal.Function.from_name(_MODAL_APP, _MODAL_FN)


async def score_batch_async(smiles: list[str], task: str) -> list[OracleResult]:
    """Score a batch via the configured backend. ``local`` wraps the harness
    subprocess in a thread (non-blocking); ``modal`` awaits the worker."""
    backend = _oracle_backend()
    if backend == "local":
        return await asyncio.to_thread(score_smiles, smiles, task)
    if backend == "modal":
        rate = oracle_usd_per_sec()
        rows = await _modal_score_fn().remote.aio(smiles, task)
        return [
            OracleResult(
                smiles=row["smiles"],
                score=row["score"],
                valid=row["valid"],
                wall_ms=row["wall_ms"],
                cost_usd=(row["wall_ms"] / 1000.0) * rate,
            )
            for row in rows
        ]
    raise ValueError(f"Set CAPYCHEM_ORACLE_BACKEND to 'local' or 'modal' (got {backend!r})")
```

```python
"""Modal worker: PMO oracle scoring (slice 4).

The image IS the legacy harness env (Python 3.10 + PyTDC 0.3.6). The harness
import/exec happens only inside the remote function body, never at module load —
so this file stays importable under modern Python 3.12 when Modal parses it.
The function shells out to the UNCHANGED harness/capychem_harness/score.py, the
same stdin/stdout JSON contract used locally, relocated into the container.
"""
from __future__ import annotations

import modal

# Mirror harness/pyproject.toml deps. PyTDC 0.3.6 has incomplete metadata, so
# requests/networkx/scipy/numpy are declared explicitly (CLAUDE.md gotcha).
# NO rdkit.six shim is needed here: score.py installs its own runtime sys.modules
# shim when executed (harness/capychem_harness/score.py) — we just ship + run it.
image = (
    modal.Image.debian_slim(python_version="3.10")
    .pip_install(
        "PyTDC==0.3.6",
        "rdkit",
        "requests",
        "networkx",
        "scipy",
        "numpy",
    )
    .add_local_dir("harness/capychem_harness", remote_path="/root/capychem_harness")
)

app = modal.App("capychem-worker")


@app.function(image=image, timeout=300)
def score(smiles: list[str], task: str) -> list[dict]:
    """Score SMILES against a PyTDC oracle inside the 3.10 container.

    Returns [{smiles, score, valid, wall_ms}] — mirrors OracleResult minus cost
    (cost policy lives modern-side in capychem.oracle)."""
    import json
    import subprocess
    import sys

    request = json.dumps({"task": task, "smiles": smiles})
    proc = subprocess.run(
        [sys.executable, "/root/capychem_harness/score.py"],
        input=request, capture_output=True, text=True, timeout=240,
    )
    for line in reversed(proc.stdout.strip().splitlines()):
        try:
            payload = json.loads(line)
        except ValueError:
            continue
        if isinstance(payload, dict) and "results" in payload:
            return payload["results"]
    raise RuntimeError(f"harness returned no JSON (exit {proc.returncode}): {proc.stderr[-500:]}")


@app.local_entrypoint()
def smoke() -> None:
    """`modal run apps/worker/app.py` — scores two molecules end to end."""
    out = score.remote(["CCO", "c1ccccc1"], "qed")
    print(out)
    assert len(out) == 2 and all("score" in r for r in out)
```

> **Verify against the installed `modal` version before trusting the exact calls** — two are version-sensitive: **(1) `image.add_local_dir(local, remote_path=...)`** is the highest-risk (older modal used `Mount`/`.copy_local_dir`, and build-time-copy vs runtime-mount semantics shifted across 0.6x); the intent is "ship `harness/capychem_harness/` into the image at `/root/capychem_harness`". **(2) `fn.remote.aio(...)`** (used in Task 2's modal backend) — the async-call surface has moved (`.aio()` vs `.remote.aio()`). Lower risk: `modal.Function.from_name(app, fn)`, `@app.function(image=, timeout=)`, `@app.local_entrypoint()`. The harness response key is already confirmed correct: `score.py` emits `{"results": [{smiles, score, valid, wall_ms}, ...]}` (same shape `oracle.py:_parse_last_json_line` consumes via `payload["results"]`).
